# @goondocks/myco-linux-x64

Linux x64 binary for [`@goondocks/myco`](https://www.npmjs.com/package/@goondocks/myco).

Linux support is experimental for the Myco 1.0 release. This package is published for early testing while macOS remains the primary supported platform.

This package is installed automatically as an `optionalDependency` of
`@goondocks/myco` when running on Linux x64. You should not install it
directly — install `@goondocks/myco` and npm will pick the matching
platform package for you.
