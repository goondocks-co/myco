# @goondocks/myco-shared

Internal helpers shared across the [Myco](https://myco.sh) monorepo —
process inspection, port discovery, browser launch, JSON parsing.

This package is published primarily to satisfy the workspace dependency
graph; it is not intended for direct external use and its API is not
covered by Myco's compatibility commitments. Pin a version if you depend
on it directly.
