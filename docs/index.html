Myco captures coding sessions. Its own agent turns that work into durable project knowledge, alongside your plans. That knowledge returns to your agents at session start and with each prompt, so the next session can build on the last.

How it works

The work becomes knowledge.

Switch agents. Start another session. Bring in a teammate. What the project has learned stays with it.

01 · Capture

Keep the work

Sessions and plans from your coding agents arrive in one Myco, across repositories and machines.

02 · Learn

Keep what matters

Myco's agent draws out decisions, discoveries and lessons as spores, updates earlier knowledge, and gives sessions useful titles. It can also learn from your repository and build a code map.

03 · Bring it back

Start with what you know

Your agents receive project instructions at session start and relevant spores and plans with each prompt. They can search further and record what they learn.

Get started

Join your Myco.

Install once, sign this machine in, then start a new coding session. Myco writes your installed agents' global configuration.

macOS and Linux

Install the native binary
curl -fsSL https://myco.sh/install.sh | sh

Windows x64

PowerShell
irm https://myco.sh/install.ps1 | iex

No Node runtime is needed. The 2.0 Windows path is not yet verified. The installers select an available 2.x release; an unqualified npm install may select 1.4.

Accept your invitation

New to the team? Run the one-time login command your administrator sends from People & machines › Invite a teammate. After you join, ask them to use Connect GitHub and send you the link to connect your account for dashboard access.

If you already sign in to the dashboard

Use your Myco’s address
myco setup --join <address>

Open the printed URL in a browser signed in to your Myco, check the code and choose Approve this machine. Repositories under ~/Repos join as you work. Start a new agent session and see it on Today.
