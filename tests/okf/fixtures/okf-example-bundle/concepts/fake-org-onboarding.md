Acme Fakeware is a fictional organization invented for this fixture. A new
project starts from `proj_fake0000000000000000000000000000`, a synthetic
project id that intentionally cannot resolve to any real Myco project.

This note exists to give the fixture bundle more than one concept, so the
directory index and duplicate-id checks in `validateBundleTree` have
something real to walk.
